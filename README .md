# Synent Task 2 - Data Visualization

## 📊 Project Overview

This project is part of my Data Science Internship at Synent Technologies.

The objective of this task is to explore and visualize the Iris dataset using Python, Pandas, and Matplotlib.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Google Colab

## 📁 Dataset

The Iris dataset contains 150 flower samples with the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## 📈 Visualizations

The project includes the following visualizations:

1. Average Petal Length by Species
2. Distribution of Petal Length
3. Distribution of Sepal Length
4. Petal Length vs Petal Width
5. Sepal Length vs Sepal Width

## 🔎 Key Insights

- Iris-setosa has the smallest average petal length.
- Iris-virginica has the largest average petal length.
- Petal length and petal width show a clear relationship across species.
- Sepal measurements have more overlap between the species.
- Data visualization helps identify patterns and relationships easily.
